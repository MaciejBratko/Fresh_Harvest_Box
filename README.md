### Fresh Harvest Box - Strona sklepu sprzedającego owoce

**Opis projektu:**
Fresh Harvest Box to strona internetowa sklepu, który specjalizuje się w sprzedaży świeżych owoców. Nasz projekt skoncentrował się na stworzeniu atrakcyjnej i intuicyjnej warstwy wizualnej z minimalnym użyciem JavaScriptu. Strona została zaprojektowana na podstawie wzorca stworzonego w oprogramowaniu Figma.

**Główne funkcjonalności:**
- Strona zawiera modalne okna, które użytkownicy mogą otwierać i zamykać za pomocą JavaScriptu.
- Stworzone elementy wizualne przyciągają uwagę i ułatwiają nawigację po stronie, zachęcając do przeglądania oferty sklepu.

**Technologie użyte w projekcie:**
- HTML
- CSS
- JavaScript

**Instalacja i uruchomienie:**
Projekt jest hostowany na GitHub Pages i jest dostępny pod adresem: [Fresh Harvest Box](https://maciejbratko.github.io/Fresh_Harvest_Box/). Wystarczy odwiedzić stronę, aby zobaczyć efekty naszej pracy.
